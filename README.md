# 🌿 EcoPack AI

> **AI-powered Sustainable Packaging Recommendation System**

EcoPackAI is an intelligent web platform that uses AI and data analytics to recommend **eco-friendly packaging materials** for different product types.  
It helps e-commerce businesses minimize their carbon footprint, reduce costs, and adopt greener packaging practices.

---

## 🧠 Abstract

The excessive use of **non-biodegradable packaging materials** has led to serious environmental challenges.  
EcoPackAI addresses this problem by analyzing **product features (weight, fragility, dimensions, etc.)** and recommending the **most suitable sustainable packaging materials** using an AI-driven recommendation engine.

It balances **sustainability, durability, and cost-effectiveness** to help industries transition toward responsible consumption.

---

## 🎯 Problem Statement

> Businesses often lack awareness or tools to compare and choose eco-friendly packaging alternatives, leading to increased plastic waste and unsustainable practices.  
EcoPackAI solves this by offering an **AI-based web tool** that recommends optimal eco-materials with data-driven insights on cost and environmental impact.

---

## ✨ Features

- 🧾 **Product Input Form:** Users enter product details like size, weight, and fragility.  
- 🤖 **AI Recommendation Engine:** Suggests eco-friendly packaging options (using rule-based / MobileNetV2 / Decision Tree).  
- 💰 **Cost and Carbon Comparison:** Displays sustainability and cost analytics.  
- 📊 **User Dashboard:** Track previous queries and visualize eco-impact metrics.  
- 📩 **Email Alerts:** Sends material recommendations and sustainability tips.  
- 🔐 **Admin Panel:** Manage packaging database and user data.
